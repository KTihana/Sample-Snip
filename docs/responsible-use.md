# Responsible use

Simple Snip is a browser audio recorder. Use it with audio you created, material whose license permits your intended use, or material you have permission to sample.

Recording a sound does not grant permission to reproduce, remix, share or sell the original material. Follow the source’s terms and applicable rights when using or sharing a sample.

The project is available free of charge through GitHub. Recording, preview and encoding run locally. Browser-store distribution is not planned.

Original code uses the MIT license. Third-party code retains its own license. Keep the encoder’s license, notices and source archive with redistributed builds.
